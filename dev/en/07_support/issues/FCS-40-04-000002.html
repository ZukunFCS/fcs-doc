FCS-40-04-000002

ERROR

Message

Create Video Folder could not complete.

Why this happens

  • Create Video Folder has several prerequisites. The sections below describe the recognized causes and their individual corrections.

How to resolve it

  1. Check the matching condition below, correct it, then retry Create Video Folder.

A video folder with that name already exists. Choose another name.

  • The Video Library already contains a video-folder group with the requested name.

  • Choose a different group name or use the existing group. This refers to the Video Library group, so renaming an unrelated directory on disk will not resolve the duplicate.

Choose two different videos to create a folder.

  • Both inputs to video-folder creation identify the same video.

  • Select two distinct Video Library entries, then create the folder again. Selecting the same entry twice does not provide two videos.

Choose two videos that are not already in a folder.

  • One of the videos selected for a new folder already belongs to a Video Library folder.

  • Select two currently ungrouped videos, or first remove the desired video from its existing group. Then create the new group.

Import the video into the current session before continuing.

  • The selected video is not registered in the current session’s Video Library.

  • Import the video into this session’s Video Library, then select that registered entry. Opening a file in another session does not register it here.

Create Video Folder stopped because of an unexpected failure. Keep your current work and the Log before retrying.

  • The Create Video Folder operation failed outside the input checks listed on this page. Its technical cause requires the operation’s Log details.

  • Preserve the current session and any files already created by Create Video Folder. Check the errors from the same operation in Log. Save available work, then retry once. If it repeats, send Bug Feedback with this code, FCS version, the operation settings and its Log.

Required fields for video.folder.create: name, source_video_stem, target_video_stem. Complete these fields before retrying. For automation, use these exact parameter names.

  • The operation was submitted without a required field.

  • Required fields for video.folder.create: name, source_video_stem, target_video_stem. Complete these fields before retrying. For automation, use these exact parameter names.
