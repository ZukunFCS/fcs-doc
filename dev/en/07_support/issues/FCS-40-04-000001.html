FCS-40-04-000001

ERROR

Why this happens

FCS could not add the selected video to this session. A missing file, an unsupported format or an unreadable video can prevent import.

How to resolve it

Find the matching file or video condition below, correct it, and retry import. Keep the original video if a readable file still fails.

Possible causes

The video file is missing

The video-import source path does not exist.

Cannot find the video. Choose an existing video file to import.

Unsupported video format

The source filename extension is not among FCS’s supported video-container extensions.

Choose an existing video with one of these extensions: .avi, .m2ts, .m4v, .mkv, .mov, .mp4, .mts, .ts; extension matching ignores case. These identify accepted containers, not a guarantee that every codec inside them can be decoded. If the original plays but cannot be read by FCS, re-encode a copy rather than merely renaming its extension.

Non-ASCII characters in the video path

The full video path contains a character outside ASCII, including a non-ASCII parent-directory or filename character.

Move or copy the video to a path using ASCII characters throughout, for example C:/FCSProject/Facial/RecData/take01.mp4. Use Latin letters, digits, hyphens or underscores for the names, and no whitespace. Import from that new location; changing only the filename does not fix a non-ASCII parent folder.

Spaces in the video path

At least one part of the full video path contains whitespace, such as a space or tab.

Remove whitespace from the video filename and every parent folder. For example, use C:/FCSProject/RecData/take_01.mp4 instead of C:/FCS Project/RecData/take 01.mp4. Import the renamed or copied file again.

The video cannot be read

FCS could not read a positive frame count and usable metadata from the selected video.

Confirm that the video plays through in a media player and has finished copying or recording. Select the complete original file. If the original plays but FCS cannot read it, re-encode a copy and keep the original for support.

No video frames can be read

The selected file yielded zero readable video frames.

Check that copying or recording has finished and the complete file plays in a media player. Choose the complete original video or re-encode a copy. Keep the original for support if a playable file still cannot be read.

FCS stopped unexpectedly

The Import Video operation failed outside the input checks listed on this page. Its technical cause requires the operation’s Log details.

Preserve the current session and any files already created by Import Video. Check the errors from the same operation in Log. Save available work, then retry once. If it repeats, send Bug Feedback with this code, FCS version, the operation settings and its Log.

Video selection

The operation was started with an incomplete selection, or FCS failed to carry the completed selection into the action.

Choose at least one existing video in the import dialog and confirm the selection. If selecting a file still produces this error, reopen the dialog and report the problem.

Video preview

The operation was started with an incomplete selection, or FCS failed to carry the completed selection into the action.

Select the source video again in the import dialog. If a selected, readable video still cannot open a preview, report the problem with the video format and FCS version.
