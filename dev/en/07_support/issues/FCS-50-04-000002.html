FCS-50-04-000002

ERROR

Why this happens

FCS could not create profiles from the selected video. The source video, reference profiles or generation options may be unavailable.

How to resolve it

Check the source video and generation options using the matching explanation below, then generate again. If a complete selection is rejected, report the generation window as an FCS problem.

Possible causes

No reference profile is available

Automatic generation needs an existing profile as a reference, but this session has none.

Create and save at least one profile in the current character’s Gallery, then retry automatic profile generation.

No facial region is enabled

General automatic profile selection has no facial region enabled.

Enable at least one of Upper, Eyelid, Gaze or Lower in the automatic-generation options, then generate again.

Saved frame-selection mode cannot be used

The profile-generation window has a saved selection that FCS cannot apply.

Reopen the profile-generation window and select the intended mode again. If a mode shown by FCS still fails, report the problem; changing unrelated video settings will not repair it.

The source video is missing

Automatic profile generation cannot find its selected source video.

Cannot find the video. Restore or reimport it before generating profiles.

No character session is open

FCS cannot resolve the current character’s RetargetData directory because the session has no complete character location.

Open a session with a project, Actor and Character. The character data is under project/FCS/Actor/Character, with RetargetData below it. Retry the profile operation after opening the intended character.

FCS stopped unexpectedly

The Generate Profiles operation failed outside the input checks listed on this page. Its technical cause requires the operation’s Log details.

Preserve the current session and any files already created by Generate Profiles. Check the errors from the same operation in Log. Save available work, then retry once. If it repeats, send Bug Feedback with this code, FCS version, the operation settings and its Log.

Generation options

The operation was started with an incomplete selection, or FCS failed to carry the completed selection into the action.

Select the source video and the intended profile-generation options, then generate again. If all visible choices are set and this error returns, report the generation dialog as an FCS problem.
