FCS-95-01-000005

ERROR

Why this happens

Session export checks the destination, Actor and Character, selected media, and any replacement DCC scene before copying the session.

How to resolve it

Use the matching check below, correct the export settings, then click Export again. The current session remains the source.

Possible causes

Missing export information

Choose an export destination and enter both Actor and Character. The exported session is created at destination/FCS/Actor/Character.

Destination overlaps the current session

The destination character folder must be outside the current character folder. It must not equal, contain, or be contained by the source character folder. Choose another destination, Actor, or Character.

Character already exists at the destination

The destination already contains this character folder. Choose a different destination or character name. Use replacement only if you intend to replace that existing character and have backed it up.

Videos would overwrite the current project

When exporting Associated videos or All files, choose a destination different from the current project folder. Alternatively, choose No video if a copy of the source media is not needed.

Source videos are missing

Associated videos and All files require the source videos to exist at their stored locations. Restore the original files or update their paths in Video Library, then retry. Choose No video only if the exported session does not need a media copy.

Different videos have the same filename

All files cannot flatten different source files with the same filename into one export folder. Give the source files unique filenames and update their Video Library paths, or export Associated videos instead.

Maya scene cannot be opened

When switching the exported session to Maya, select an existing .ma or .mb scene file. Use a lowercase extension. Relative paths are resolved from the export destination. Restore a missing scene or select its actual location.

Maya project folder is unavailable

When switching to Maya, choose an existing Maya workspace directory. Select the folder itself, not a scene file. Reconnect an unavailable drive before choosing the folder again.

Blender scene cannot be opened

When switching the exported session to Blender, choose an existing .blend scene file. Extension matching is case-insensitive. Relative paths are resolved from the export destination.

Saved application selection cannot be used

Choose Maya or Blender for the exported session. Selecting another renderer is not supported.

Export settings

The operation was started with an incomplete selection, or FCS failed to carry the completed selection into the action.

In Export Session, choose a destination and enter Actor and Character, then try Export again. If they were already filled in, close and reopen the export window; report the problem if it returns.

Export settings

The operation was started with an incomplete selection, or FCS failed to carry the completed selection into the action.

In Export Session, choose a destination and enter Actor and Character. If the completed form is still rejected, reopen the window and report the problem with a screenshot.

Unsupported Maya version

For Maya export, select a supported four-digit version: 2018, 2020, 2022, 2023, 2024, 2025, 2026, 2027.

Unsupported Blender version

For Blender export, select a supported major.minor version: 4.0, 4.1, 4.2, 4.3, 4.4, 4.5. For example, use 4.5 rather than 4.5.0.
