Unexpected failure

Back to lookup and families

General

Code

Description

FCS-00-99-000001

The result may be incomplete. Keep completed outputs and copy this code and the Log message to support. Open help for recovery steps.

FCS-00-99-000002

The requested action could not complete. Copy this code and the Log message when contacting support.

Application and settings

Code

Description

FCS-10-99-000001

FCS could not finish shutting down normally. Contact support if the application remains open.

FCS-10-99-000002

The support-report window could not be opened. Contact support by another available channel.

FCS-10-99-000003

The selected language could not be applied. Choose another language or contact support.

FCS-10-99-000004

The requested action could not be completed. Check the selection or contact support.

FCS-10-99-000005

The automation settings could not be applied. Check the selected port and try again, or contact support.
