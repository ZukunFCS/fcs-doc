FCS-10-08-000003

Landmark-frame export is deprecated. Contact support if your workflow depends on this output.

Profiles

Code

Description

FCS-50-08-000001

Some profile constraints exceeded the controller limits and were clamped. Check the affected poses.

FCS-50-08-000002

Conflicting profile constraints were found at the same frame. FCS kept the first value. Check the affected profiles.

FCS-50-08-000003

Some profile constraints could not be used. Check that their controllers and values match the current character.

FCS-50-08-000004

Some profile constraints were skipped because their source frame or controller values are unavailable. Check the affected profiles.

FCS-50-08-000005

A face could not be located in some profiles; the full images were used. Replace unclear or incorrectly oriented images, check the landmarks, and retrain.

FCS-50-08-000006

A profile already exists at this frame. Select it in Gallery to edit it.

FCS-50-08-000007

The profile has unsaved changes. Save or discard them before continuing.

FCS-50-08-000008

A profile image could not be displayed. Check its source image or contact support.

FCS-50-08-000009

Some profiles could not be loaded and are missing from Gallery. Contact support before saving over the original session.

FCS-50-08-000010

Some profiles could not be loaded. They may be absent from Gallery. Contact support before saving changes over the original session.

FCS-50-08-000011

The requested profile-priority option could not be applied. The completed animation is available without that option.

FCS-50-08-000012

Open a profile in Gallery before editing it.

Description

Description

Description
