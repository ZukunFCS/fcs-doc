FCS 26.10.01

Date: 2026/10/09 Version: 26.10.01 Stage: Stable


Added / New

  • Added Blender support for operations and animation output, including session creation and export, connection controls, timeline and controller synchronization, animation transfer, scene saving, and installation of the bundled Blender add-on. A tutorial video will be published later.


  • Added the enhanced Robust+++ and RP+++ algorithms with integrated post-processing to the Solver. Registered Profile expressions are reflected more directly, with clearer eye and mouth opening and closure. These profiles are recommended for stronger expression contrast while preserving the character’s identity.

    Comparison video with previous pipelines. The example uses 35 Profiles: 26 from the Starter Kit ROM video and 9 from this video.


  • Added a local Model Context Protocol (MCP) server for FCS users in Settings. Enable the setting before use. See Technical Manual / Operating FCS with an AI Agent (MCP) for setup and details.


  • Added UI customization under File ▶ Settings ▶ UI. See Preferences for details.


  • Added a detailed Profile list to the Gallery. Use the button at the top left (labelled “switch to ~”) to switch between List view and Pictures view. List view also supports Profile setting changes such as removing tags.


  • Unified Region colors across the Gallery, Profile Editor, and Controller windows.


  • Added From Maya and From Blender buttons to Controller Info to retrieve and apply the selected controllers’ Default, Min, and Max values from the DCC.


  • Added explicit Auto, D3D, DirectML, and CPU processing backend choices. Auto switches to an available backend automatically.


Changes / Improvements

  • Improved video tracking performance and reliability through native video decoding, faster inference paths, better handling of rotated videos, and recovery when a face is not detected.


  • Reduced waiting during Profile training and video processing by running independent uploads and analysis in parallel.

    FCS 26.10 introduces improved animation analysis algorithms for higher-quality animation and faster inference. These are statistical analysis algorithms developed by TOEI Zukun Laboratory, not generative AI.

    Some processing runs in the FCS cloud service, but original images, video frames, and 3D assets are never uploaded. Only expression estimation parameters that do not identify individuals and controller parameters needed to generate animation are transmitted. These parameters contain no original image, video, or 3D model data.


  • Improved responsiveness when loading sessions and Profiles, filtering large Galleries and Video Libraries, scrubbing video, and transferring animation to a DCC.


  • Improved loading indicators, per-video and overall export progress, estimated time remaining, cancellation controls, and warning and error displays.


  • Improved loading sessions across versions with version warnings, migration backups, and removal of incompatible caches.


Fixes

  • Fixed inaccessible recent-session entries and populated the recent-session menu correctly at startup.


  • Fixed seeking and scrubbing for videos with negative timestamps. Also improved retention of the final frame at the end of supported videos.


  • Fixed the interface becoming unresponsive during video processing and overlapping background processing jobs.


  • Fixed Gallery filtering, Editor tag suggestions, and Profile controls failing to refresh after edits.


  • Fixed DCC launch and synchronization after a connection loss, including Controller Info imports. Also improved animation upload speed and Maya 2023 compatibility.


  • Fixed Controller Info items failing to rearrange and video resize failures.


  • Fixed settings-triggered restarts and incorrect display when translation text is missing. Also prevented unwanted console windows when starting the application through the launcher.
