# FCS-30-04-000002

ERROR

## 原因

選択したプロジェクト内に、新しいアクターを作成できませんでした。

## 対処方法

以下の該当する項目でプロジェクトの場所とアクター名を確認してから、再度作成してください。

## 考えられる原因

```{raw} html
<span id="invalid-project-folder"></span>
```

**選択したフォルダーがFCSプロジェクトではない**

アクターの作成にはFCS、Facial、Facial/RecDataフォルダーを含むプロジェクトのルートが必要です。通常のファイルをフォルダーとして指定することもできません。

FacialやFCSの内部ではなく、プロジェクトのルートを選択してください。新規プロジェクトはFCSの作成機能で必要なフォルダーを作成してください。既存プロジェクトで不足するフォルダーは、元のバックアップから復元してください。

```{raw} html
<span id="invalid-session-name"></span>
```

**ActorまたはCharacterが空欄**

ActorまたはCharacterの名前が空か、空白のみになっています。

ActorとCharacterに空白以外の名前（例：Actor01、Character01）を入力して再実行してください。この検証に数値の範囲制限はありません。

```{raw} html
<span id="actor-folder-exists"></span>
```

**同じ名前のアクターが存在**

プロジェクトのFCSフォルダー内に、同じ名前のアクターフォルダーが存在します。

同じ名前のアクターフォルダーが既に存在します。別の名前を選ぶか、既存のアクターを開いてください。

```{raw} html
<span id="unexpected"></span>
```

**FCSで予期しない障害が発生**

アクターの作成で、このページに列挙した入力検証以外の障害が発生しました。技術的な原因の特定には、この操作のログが必要です。

現在のセッションとアクターの作成で作成済みのファイルを保持してください。同じ操作のログのエラーを確認してください。保存できる作業を保存し、一度再実行してください。再発する場合は、このコード、FCSバージョン、操作の設定、ログを添えてBug Feedbackで報告してください。

```{raw} html
<span id="required-session-actor-create"></span>
```

**新しいアクターの情報**

選択が不完全な状態で開始されたか、選択済みの内容をFCSが操作に渡せませんでした。

セッションの作成画面でFCSプロジェクトのフォルダーを選び、新しいActor名を入力してください。両方とも設定済みの場合は画面を開き直し、問題を報告してください。
