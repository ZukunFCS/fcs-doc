# FCS-10-01-000009

ERROR

## メッセージ

処理設定を適用できませんでした。

## 原因

- 数値、スムージング方式、視線の置換方法、プロファイル優先設定、またはクランプ方式が、処理設定の条件を満たしていません。以下はそれぞれ独立した条件です。変更した設定を修正してください。

## 対処方法

1. 同一動画の重みは 1.0 以上 10.0 以下です。例えば5は有効です。
2. 視線固定のしきい値は 0.0 以上 1.0 以下です。例えば0.5は有効です。置換方法は Last detected または Default value です。
3. プロファイル優先の範囲は 0.0 ～ 2.0 秒（両端を含む）、指数は 0.1 ～ 5.0（両端を含む）です。例えば範囲1秒、指数1は有効です。優先モードは現在の処理プロファイルで表示される候補から選んでください。候補はプロファイルによって異なります。
4. スムージング方式は Smoothing、Peak、1€、Raw のいずれかです。1€の最小カットオフは0より大きい有限値、betaは0以上の有限値です。微分カットオフは内部で1に固定されます。
5. クランプ方式は No Clamp、Hard Clamp、Soft Clamp のいずれかです。自動操作では翻訳したラベルを渡さず、アプリが示す値を使用してください。
6. 処理設定の該当する項目を修正し、再度適用してください。自動操作では processing.settings が返すフィールド名と階層を使用し、非対応のキーを追加しないでください。

```{raw} html
<span id="same-video-weight"></span>
```
