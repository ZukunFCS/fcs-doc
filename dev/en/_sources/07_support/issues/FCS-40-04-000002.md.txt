# FCS-40-04-000002

ERROR

## メッセージ

動画グループの作成を完了できませんでした。

## 原因

- 動画グループの作成には複数の前提条件があります。以下に既知の原因と、それぞれの修正方法を示します。

## 対処方法

1. 以下の該当する条件を確認し、修正してから動画グループの作成を再実行してください。

```{raw} html
<span id="video-folder-name-duplicate"></span>
```

## 同じ名前の動画フォルダーが既に存在します。別の名前を選択してください。

- Video Libraryに同じ名前の動画グループが存在します。
- 別のグループ名を指定するか、既存のグループを使用してください。これはVideo Library内のグループ名の問題です。無関係なディスク上のフォルダーを変更しても解決しません。

```{raw} html
<span id="video-folder-same-video"></span>
```

## フォルダーを作成するには、異なる2つの動画を選択してください。

- 動画グループの作成に指定した2つの入力が同じ動画です。
- Video Libraryで異なる2つの動画を選択してから、再度グループを作成してください。同じ項目を2回選択しても、2本の動画にはなりません。

```{raw} html
<span id="video-folder-create-requires-ungrouped"></span>
```

## まだフォルダーに入っていない2つの動画を選択してください。

- 新しいグループに指定した動画の少なくとも1つが、既存のVideo Libraryグループに属しています。
- 現在どのグループにも属していない2本の動画を選択するか、先に対象の動画を既存のグループから外してください。その後で新しいグループを作成してください。

```{raw} html
<span id="video-not-registered"></span>
```

## 続行する前に現在のセッションに動画をインポートしてください。

- 選択した動画が現在のセッションのVideo Libraryに登録されていません。
- 現在のセッションのVideo Libraryに動画をインポートし、登録された項目を選択してください。別のセッションで開いただけでは、現在のセッションには登録されません。

```{raw} html
<span id="unexpected"></span>
```

## 動画グループの作成で予期しない障害が発生しました。再実行する前に現在の作業とログを保持してください。

- 動画グループの作成で、このページに列挙した入力検証以外の障害が発生しました。技術的な原因の特定には、この操作のログが必要です。
- 現在のセッションと動画グループの作成で作成済みのファイルを保持してください。同じ操作のログのエラーを確認してください。保存できる作業を保存し、一度再実行してください。再発する場合は、このコード、FCSバージョン、操作の設定、ログを添えてBug Feedbackで報告してください。

```{raw} html
<span id="required-video-folder-create"></span>
```

## video.folder.create の必須項目は name, source_video_stem, target_video_stem です。入力してから再実行してください。自動操作では、これらのパラメーター名をそのまま使用してください。

- 操作に必要なフィールドが指定されていません。
- video.folder.create の必須項目は name, source_video_stem, target_video_stem です。入力してから再実行してください。自動操作では、これらのパラメーター名をそのまま使用してください。
