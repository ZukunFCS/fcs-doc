# FCS-55-04-000002

ERROR

## 原因

保存時にコントローラー名、顔領域の割り当て、数値の範囲を検証します。

## 対処方法

以下の該当する原因を確認し、コントローラー表を修正してから再度保存してください。

## 考えられる原因

```{raw} html
<span id="missing-regions"></span>
```

**コントローラーのない顔領域がある**


必要な各顔領域にコントローラーが1つ以上必要です。不足している領域に割り当ててから、再度保存してください。

```{raw} html
<span id="invalid-region"></span>
```

**コントローラーの領域が未設定**


各コントローラーに顔の領域を指定する必要があります。未割り当てのコントローラーに領域を選択してから、再度保存してください。

```{raw} html
<span id="duplicate-name"></span>
```

**コントローラー名が重複**


コントローラー名は重複できません。重複する行の名前を変更するか、行を削除してから、再度保存してください。

```{raw} html
<span id="invalid-range"></span>
```

**最小値と最大値が近すぎるか逆順**


最大値は最小値より0.0001以上大きくする必要があります。最大値を上げるか最小値を下げてから、再度保存してください。例えば、最小値0、最大値1は有効です。
