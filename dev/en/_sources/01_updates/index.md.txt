## リリースノート

[FCSはこちらからダウンロード](https://github.com/ZukunFCS/fcs-doc/releases)

### FCS 26.10.01
日付: 2026/10/01  
バージョン: 26.10.01  
ステージ: ステーブル  

<br>

```{rubric} 新機能 / 追加項目
```
 - Blenderでの操作・アニメーション出力に対応しました。  
   Sessionの作成やExport、Blenderとの接続、Timelineやcontrollerの同期、アニメーション転送、シーン保存、および付属のBlenderアドオンのインストールに対応しました。

 - Solverに新たな処理アルゴリズム **『Robust+++』** / **『RP+++』** を追加しました。
   
 - FCSユーザーが利用できるローカルのModel Context Protocol（MCP）サーバーをSettingsに追加しました。  
   ※利用には設定の有効化が必要です。  
   設定方法・詳細については[テクニカルマニュアル/AIエージェントによるFCSの操作(MCP)](https://zukunfcs.github.io/fcs-doc-advanced/26.10/jp/005_mcp.html)を参照ください。  

 - UIをカスタマイズできる機能を追加しました。  
   File ▶ Settingsウィンドウ ▶ UI よりカスタマイズ可能です。  
   ※詳しくは[**環境設定**](../06_glossary/01_Menu/settings) を参照ください。  

 - Galleryにprofileの詳細一覧表示を追加しました。  
   Gallery左上のボタン（『switch to ~』と表示されます）より、
   詳細一覧（List view）と画像一覧（Pictures view）の表示切り替えが可能になりました。  
   詳細一覧（List view）ではタグの削除などprofileの設定変更が可能です。  

 - Gallery・Profile Editor・Controllerの各ウィンドウでRegionの色分けを統一しました。  

 - Controller Infoに【From Maya】/【From Blender】ボタンを追加しました。  
   選択したコントローラーの Default・Min・Maxの値を DCC から取得して適用します。  

 - 処理バックエンドとして『Auto / D3D / DirectML / CPU』を明示的に選択できるようになりました。  
   『Auto』選択時は利用可能なバックエンドへ自動的に切り替えます。  
 
<br>

```{rubric} 変更 / 改善
```
 - ネイティブビデオデコードや高速推論経路、回転した動画の処理改善、  
   顔を検出できなかった場合の復旧機能の導入により、ビデオトラッキングの性能と信頼性を向上しました。   
   
 - 独立したアップロード処理と解析処理を並行して実行することで、profileなどの学習および動画処理の待ち時間を短縮しました。

   FCS 26.10では、より高品質なアニメーションと高速な推論を実現するため、改良されたアニメーション解析アルゴリズムを導入しました。  
   これは **東映ツークン研究所が開発した統計的な手法に基づく解析アルゴリズムであり、生成AIではありません。**   

   処理の一部はFCSのクラウドサービスで実行されます、元の画像・動画フレームや3Dアセットがクラウドへアップロードされることはありません。  
   送信されるのは、個人の特定ができないような表情推定結果パラメータと、アニメーション生成に必要なコントローラーパラメータのみです。  
   これらのパラメータには、元の画像・動画や3Dモデルのデータは含まれません。

 
 - 一部操作の応答性を向上しました。  
   （sessionおよびprofileの読み込み、大量のGalleryとVideo Libraryの絞り込み、動画のスクラブ、DCC へのアニメーション転送）

 - 読み込み状態、出力時の動画ごと・全体の進捗、推定残り時間、キャンセル操作、警告・エラーなどの表示を改善しました。  

 - バージョン警告や移行時のバックアップ、および互換性のないキャッシュの削除により、異なるバージョン間でのsession読み込みを改善しました。  

<br>

```{rubric} 修正
```

 - アクセスできなかった『recent-session』の項目を修正し、起動時に『recent-session』メニューが正しく表示されるようにしました。

 - 負のタイムスタンプを持つ動画における、シークバーおよびスクラブ操作の不具合を修正しました。  
   また、対応動画の終端において最終フレームが正しく保持されるよう改善しました。  

 - 動画処理中に操作不能になる問題や、バックグラウンドの処理が重複して実行される問題を修正しました。

 - 編集時に、Galleryの絞り込み・Editorのタグ候補・profileのコントロールなどが更新されない問題を修正しました。  

 - 通信切断後のDCCツールの起動および同期（コントローラー情報の読み込みなど）が正しく行われない問題を修正しました。  
   併せて、アニメーションのアップロード速度を向上し、Maya 2023との互換性を改善しました。  

 - Controller Infoの項目が並べ替えられない問題や動画のサイズ変更に失敗する問題を修正しました。  
   
 - 設定変更に伴う再起動の不具合や翻訳テキストが見つからない場合に表示がおかしくなる問題を修正しました。  
   また、ランチャーから起動した際に不要なプログラム画面（コンソールウィンドウ）が開いてしまう問題を修正しました。
