# FCS-30-04-000004

ERROR

## メッセージ

アクター名の変更を完了できませんでした。

## 原因

- アクター名の変更には複数の前提条件があります。以下に既知の原因と、それぞれの修正方法を示します。

## 対処方法

1. 以下の該当する条件を確認し、修正してからアクター名の変更を再実行してください。

```{raw} html
<span id="invalid-session-name"></span>
```

## ActorとCharacterに空白以外の名前を入力して、再実行してください。

- ActorまたはCharacterの名前が空か、空白のみになっています。
- ActorとCharacterに空白以外の名前（例：Actor01、Character01）を入力して再実行してください。この検証に数値の範囲制限はありません。

```{raw} html
<span id="actor-name-unchanged"></span>
```

## 別のアクター名を入力してください。

- 新しいアクター名が現在の名前と同じため、名前を変更できません。
- 空白以外の別のアクター名を入力して再実行するか、現在の名前でよければ名前の変更をキャンセルしてください。

```{raw} html
<span id="actor-folder-exists"></span>
```

## 同じ名前のアクターフォルダーが既に存在します。別の名前を選ぶか、既存のアクターを開いてください。

- プロジェクトのFCSフォルダー内に、同じ名前のアクターフォルダーが存在します。
- 同じ名前のアクターフォルダーが既に存在します。別の名前を選ぶか、既存のアクターを開いてください。

```{raw} html
<span id="actor-folder-in-use"></span>
```

## このアクターのファイルやフォルダーを閉じてから、名前の変更をもう一度お試しください。

- アクターフォルダーまたは内部のファイルへのアクセスが拒否され、名前を変更できませんでした。
- このアクター内のファイルを使用しているMayaやBlenderのシーン、ファイルのプレビューなどを閉じてください。エクスポートが書き込み中でないことを確認してから再実行してください。拒否が続く場合は、フォルダーの権限とドライブ接続を確認してください。

```{raw} html
<span id="actor-folder-not-found"></span>
```

## アクターフォルダーが見つかりません。既存のアクターを選択するか、フォルダーを復元してください。

- プロジェクトのFCSフォルダー内に、選択したアクターのフォルダーがありません。
- アクターフォルダーが見つかりません。既存のアクターを選択するか、フォルダーを復元してください。

```{raw} html
<span id="unexpected"></span>
```

## アクター名の変更で予期しない障害が発生しました。再実行する前に現在の作業とログを保持してください。

- アクター名の変更で、このページに列挙した入力検証以外の障害が発生しました。技術的な原因の特定には、この操作のログが必要です。
- 現在のセッションとアクター名の変更で作成済みのファイルを保持してください。同じ操作のログのエラーを確認してください。保存できる作業を保存し、一度再実行してください。再発する場合は、このコード、FCSバージョン、操作の設定、ログを添えてBug Feedbackで報告してください。

```{raw} html
<span id="required-session-rename-actor"></span>
```

## session.rename_actor の必須項目は actor です。入力してから再実行してください。自動操作では、これらのパラメーター名をそのまま使用してください。

- 操作に必要なフィールドが指定されていません。
- session.rename_actor の必須項目は actor です。入力してから再実行してください。自動操作では、これらのパラメーター名をそのまま使用してください。
