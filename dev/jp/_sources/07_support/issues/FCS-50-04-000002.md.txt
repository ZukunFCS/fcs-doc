# FCS-50-04-000002

ERROR

## 原因

選択した動画からプロファイルを作成できませんでした。元動画、参照プロファイル、生成の設定を使用できない場合があります。

## 対処方法

以下の該当する説明で元動画と生成の設定を確認してから再実行してください。すべて選択済みでも拒否される場合は、生成画面の問題として報告してください。

## 考えられる原因

```{raw} html
<span id="auto-profile-requires-profile"></span>
```

**参照プロファイルがない**

自動生成の参照に必要な既存のプロファイルが、このセッションにありません。

現在のキャラクターのGalleryにプロファイルを1つ以上作成して保存し、再度自動生成してください。

```{raw} html
<span id="auto-profile-no-region-enabled"></span>
```

**有効な顔領域がない**

Generalによるプロファイルの自動選択で、有効な顔領域がありません。

自動生成のオプションでUpper、Eyelid、Gaze、Lowerの少なくとも1つを有効にしてから再実行してください。

```{raw} html
<span id="auto-profile-invalid-selection"></span>
```

**保存されたフレーム選択方法を使用できない**

プロファイルの自動生成画面で、保存された選択内容をFCSが適用できませんでした。

プロファイルの自動生成画面を開き直し、使用する方法を選び直してください。表示された選択肢でも失敗する場合は、問題を報告してください。無関係な動画設定を変更しても復旧できません。

```{raw} html
<span id="auto-profile-video-not-found"></span>
```

**元動画が見つからない**

プロファイルの自動生成で、選択した元動画を見つけられませんでした。

動画が見つかりません。復元または再インポートしてからプロファイルを生成してください。

```{raw} html
<span id="session-retarget-folder-missing"></span>
```

**キャラクターのセッションが開かれていない**

セッションのキャラクターの場所が未設定のため、RetargetDataフォルダーを特定できません。

プロジェクト、Actor、Characterが設定されたセッションを開いてください。キャラクターデータは プロジェクト/FCS/Actor/Character にあり、その下にRetargetDataがあります。対象のキャラクターを開いてからプロファイル操作を再実行してください。

```{raw} html
<span id="unexpected"></span>
```

**FCSで予期しない障害が発生**

プロファイルの自動生成で、このページに列挙した入力検証以外の障害が発生しました。技術的な原因の特定には、この操作のログが必要です。

現在のセッションとプロファイルの自動生成で作成済みのファイルを保持してください。同じ操作のログのエラーを確認してください。保存できる作業を保存し、一度再実行してください。再発する場合は、このコード、FCSバージョン、操作の設定、ログを添えてBug Feedbackで報告してください。

```{raw} html
<span id="required-rom-gallery-auto-profile-generate"></span>
```

**自動生成の設定**

選択が不完全な状態で開始されたか、選択済みの内容をFCSが操作に渡せませんでした。

元動画とプロファイル生成の設定を選択してから再実行してください。画面上の項目を設定済みでも再発する場合は、自動生成画面の問題として報告してください。
