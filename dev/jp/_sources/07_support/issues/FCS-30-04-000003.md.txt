# FCS-30-04-000003

ERROR

## メッセージ

キャラクターの作成を完了できませんでした。

## 原因

- キャラクターの作成には複数の前提条件があります。以下に既知の原因と、それぞれの修正方法を示します。

## 対処方法

1. 以下の該当する条件を確認し、修正してからキャラクターの作成を再実行してください。

```{raw} html
<span id="invalid-project-folder"></span>
```

## 既存のプロジェクトフォルダーを選択してください。

- アクターの作成にはFCS、Facial、Facial/RecDataフォルダーを含むプロジェクトのルートが必要です。通常のファイルをフォルダーとして指定することもできません。
- FacialやFCSの内部ではなく、プロジェクトのルートを選択してください。新規プロジェクトはFCSの作成機能で必要なフォルダーを作成してください。既存プロジェクトで不足するフォルダーは、元のバックアップから復元してください。

```{raw} html
<span id="invalid-session-name"></span>
```

## ActorとCharacterに空白以外の名前を入力して、再実行してください。

- ActorまたはCharacterの名前が空か、空白のみになっています。
- ActorとCharacterに空白以外の名前（例：Actor01、Character01）を入力して再実行してください。この検証に数値の範囲制限はありません。

```{raw} html
<span id="actor-folder-not-found"></span>
```

## アクターフォルダーが見つかりません。既存のアクターを選択するか、フォルダーを復元してください。

- プロジェクトのFCSフォルダー内に、選択したアクターのフォルダーがありません。
- アクターフォルダーが見つかりません。既存のアクターを選択するか、フォルダーを復元してください。

```{raw} html
<span id="character-folder-exists"></span>
```

## 同じ名前のキャラクターフォルダーが既に存在します。別の名前を選ぶか、既存のキャラクターを開いてください。

- 選択したアクター内に、同じ名前のキャラクターフォルダーが存在します。
- 同じ名前のキャラクターフォルダーが既に存在します。別の名前を選ぶか、既存のキャラクターを開いてください。

```{raw} html
<span id="unexpected"></span>
```

## キャラクターの作成で予期しない障害が発生しました。再実行する前に現在の作業とログを保持してください。

- キャラクターの作成で、このページに列挙した入力検証以外の障害が発生しました。技術的な原因の特定には、この操作のログが必要です。
- 現在のセッションとキャラクターの作成で作成済みのファイルを保持してください。同じ操作のログのエラーを確認してください。保存できる作業を保存し、一度再実行してください。再発する場合は、このコード、FCSバージョン、操作の設定、ログを添えてBug Feedbackで報告してください。

```{raw} html
<span id="required-session-character-create"></span>
```

## session.character.create の必須項目は project_folder, actor, character です。入力してから再実行してください。自動操作では、これらのパラメーター名をそのまま使用してください。

- 操作に必要なフィールドが指定されていません。
- session.character.create の必須項目は project_folder, actor, character です。入力してから再実行してください。自動操作では、これらのパラメーター名をそのまま使用してください。
