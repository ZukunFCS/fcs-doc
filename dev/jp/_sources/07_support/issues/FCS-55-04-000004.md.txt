# FCS-55-04-000004

ERROR

## メッセージ

コントローラー上下限の貼り付けを完了できませんでした。

## 原因

- コントローラー上下限の貼り付けには複数の前提条件があります。以下に既知の原因と、それぞれの修正方法を示します。

## 対処方法

1. 以下の該当する条件を確認し、修正してからコントローラー上下限の貼り付けを再実行してください。

```{raw} html
<span id="invalid-controller-clipboard"></span>
```

## 有効なコントローラーの制限値をコピーしてから貼り付けてください。

- コントローラー上下限のクリップボードがカンマ区切りの数値3つでないか、上下限の条件を満たしていません。
- 最小値,最大値,デフォルト値の順に指定してください（例：0,1,0.5）。最大値は最小値より 0.0001 以上大きくしてください。既存のコントローラーから上下限をコピーして、再度貼り付けることを推奨します。

```{raw} html
<span id="invalid-controller-range"></span>
```

## コントローラーの上下限には有限値を入力し、最大値を最小値より 0.0001 以上大きくしてください。

- コントローラーの上下限が逆順、同値、非有限値、または差が 0.0001 未満です。
- 最小値と最大値には有限の数値を入力し、最大値 − 最小値を 0.0001 以上にしてください。例えば0と1は有効です。最大値を上げるか最小値を下げてください。一律の−1～1という制限はありません。

```{raw} html
<span id="unexpected"></span>
```

## コントローラー上下限の貼り付けで予期しない障害が発生しました。再実行する前に現在の作業とログを保持してください。

- コントローラー上下限の貼り付けで、このページに列挙した入力検証以外の障害が発生しました。技術的な原因の特定には、この操作のログが必要です。
- 現在のセッションとコントローラー上下限の貼り付けで作成済みのファイルを保持してください。同じ操作のログのエラーを確認してください。保存できる作業を保存し、一度再実行してください。再発する場合は、このコード、FCSバージョン、操作の設定、ログを添えてBug Feedbackで報告してください。
