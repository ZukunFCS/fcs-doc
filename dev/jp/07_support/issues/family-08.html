代替動作・結果の制限

検索・種類の一覧に戻る

アプリケーションと設定

コード

説明

FCS-10-08-000001

{action}：制限付きで完了しました。関連する警告を確認し、問題を解決してから対象の結果を使用してください。

FCS-10-08-000002

自動操作の接続が正常に終了しませんでした。再起動できない場合はサポートにお問い合わせください。

FCS-10-08-000003

ランドマークフレームのエクスポートは非推奨です。この出力を必要とするワークフローを使用している場合は、サポートにお問い合わせください。

FCS-10-08-000004

一部の動画フレームをスキップしました。アニメーションが不完全、または同期がずれている可能性があります。再発する場合はサポートにお問い合わせください。

FCS-10-08-000005

アプリケーション画面の一部を更新できませんでした。サポートにお問い合わせください。

プロジェクトとセッション

コード

説明

FCS-30-08-000001

再起動前にセッションのロックを解除できませんでした。開き直せない場合はサポートにお問い合わせください。

動画とメディア

コード

説明

FCS-40-08-000001

動画の時間情報を読み取れなかったため、保存済みの時間情報を使用しました。結果を使用する前にフレームレートと範囲を確認し、正しくない場合は動画を再インポートしてください。

プロファイル

コード

説明

FCS-50-08-000001

一部のプロファイル拘束がコントローラーの制限値を超えたため、範囲内に制限しました。対象のポーズを確認してください。

FCS-50-08-000002

同じフレームに矛盾するプロファイル拘束がありました。FCSは最初の値を保持しました。対象のプロファイルを確認してください。

FCS-50-08-000003

一部のプロファイル拘束を使用できませんでした。コントローラーと値が現在のキャラクターに対応しているか確認してください。

FCS-50-08-000004

元フレームまたはコントローラー値を使用できないため、一部のプロファイル拘束をスキップしました。対象のプロファイルを確認してください。

FCS-50-08-000005

一部のプロファイルで顔の位置を特定できなかったため、画像全体を使用しました。不鮮明な画像や向きが正しくない画像を置き換え、ランドマークを確認してから再学習してください。

FCS-50-08-000006

このフレームには既にプロファイルが存在します。編集するにはギャラリーで選択してください。

FCS-50-08-000007

プロファイルに未保存の変更があります。保存または破棄してから続行してください。

FCS-50-08-000008

プロファイル画像を表示できませんでした。元画像を確認するか、サポートにお問い合わせください。

FCS-50-08-000009

一部のプロファイルを読み込めず、ギャラリーに表示されていません。元のセッションに上書き保存する前にサポートにお問い合わせください。

FCS-50-08-000010

一部のプロファイルを読み込めませんでした。ギャラリーに表示されていない可能性があります。元のセッションに変更を上書き保存する前に、サポートにお問い合わせください。

FCS-50-08-000011

指定されたプロファイル優先オプションを適用できませんでした。このオプションなしで完成したアニメーションを使用できます。

FCS-50-08-000012

編集する前にギャラリーでプロファイルを開いてください。

コントローラー

コード

説明

FCS-55-08-000001

DCCからの読み込みウィザードを適用する前に、必要なコントローラー値をキャプチャーしてください。

FCS-55-08-000003

一部のコントローラーの動きの除外設定を無視しました。コントローラーの対応付けと予測された動きを確認し、対応付けを修正して再学習するか、サポートにお問い合わせください。

FCS-55-08-000004

一部のコントローラーの制限値が無効です。結果を使用する前にコントローラー設定を確認してください。

FCS-55-08-000006

先に1つ以上のコントローラーを選択してください。

FCS-55-08-000007

一部のプロファイルがコントローラー一覧と一致しないため、コントローラー値をリセットしました。保存前に対象のポーズを確認してください。

FCS-55-08-000008

領域のオーバーライド用のコントローラー値が選択されていません。

学習とソルバー

コード

説明

FCS-60-08-000001

ニュートラルのプロファイルが選択されていません。最初のプロファイルをニュートラルとして使用します。リラックスした表情であることを確認してください。

処理と予測

コード

説明

FCS-70-08-000001

一部のアニメーション値を読み取れなかったため、置き換えました。インポートしたアニメーションを確認してください。

FCS-70-08-000002

一部のアニメーション値が無効なため修復しました。結果を使用する前に対象箇所を確認し、サポートにお問い合わせください。

FCS-70-08-000004

一部のアニメーション調整を適用できませんでした。反映された動きと学習ウィンドウの設定を確認してから、適用できなかった調整を再試行してください。

FCS-70-08-000005

トラッキングシーケンスがこの動画と一致しないため、インポートしませんでした。対応する動画とシーケンスを選択してください。

FCS-70-08-000006

保存済みのトラッキングシーケンスを読み取れませんでした。動画を再処理するか、サポートにお問い合わせください。

Maya・Blenderへの出力

コード

説明

FCS-80-08-000003

シーンの時間設定を更新できませんでした。アニメーションを使用する前にシーンのフレームレートと範囲を確認し、MayaまたはBlenderに再接続してから再試行してください。

FCS-80-08-000010

次の出力調整を使用できませんでした：{outputs}。完成した結果と選択した設定を確認し、対象の調整を再試行してください。

FCS-80-08-000011

出力調整の一部を完了できませんでした。完成したアニメーションを確認し、このコードとログのメッセージをコピーしてサポートにお問い合わせください。復旧手順はヘルプで確認してください。

FCS-80-08-000012

接続の失敗によりレンダラーの自動同期を無効にしました。MayaまたはBlenderに再接続してから有効にし直してください。
