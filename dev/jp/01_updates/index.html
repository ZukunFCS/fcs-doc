FCS 26.10.01

日付: 2026/08/25 バージョン: 26.10.01 ステージ: ステーブル

新機能 / 追加項目

  • Blenderでの操作・アニメーション出力に対応しました。
    Sessionの作成やExport、Blenderとの接続、Timelineとｋｐの同期、アニメーション転送、シーン保存、および付属 Blender アドオンのインストールに対応しました。　※もう少し追記する

  • より安定したモーションと表情の関係性を実現する Robust+++ および RP+++ 処理プロファイルを Solver ウィンドウに追加しました。　※もう少し追記する

  • FCSユーザーが利用できるローカルのModel Context Protocol（MCP）サーバーをSettingsに追加しました。 ※利用には設定の有効化が必要です。
    設定方法・詳細についてはテクニカルマニュアル/AIエージェントによるFCSの操作(MCP)を参照ください。

  • 背景や各操作キー、アクセントカラー、テキストなどのUIをカスタマイズできる機能を追加しました。
    File ▶ Settingsウィンドウ ▶ UI よりカスタマイズ可能です。
    詳しくは環境設定 を参照ください。

  • Galleryにprofileの詳細一覧表示を追加しました。
    Gallery左上のボタン（『switch to ~』と表示されます）より、詳細一覧（List view）と画像一覧（Pictures view）の表示切り替えが可能になりました。 詳細一覧（List view）ではタグの削除などprofileの設定変更が可能です。

  • Gallery・Profile Editor・Controllerの各ウィンドウでRegionの色分けを統一しました。

    ※以下未編集

  • Controller Infoにに応じて 【From Maya / From Blender と表示されるウィザードを追加し、選択したコントローラーの Default、Min、Max 値を DCC から取得して適用できるようにしました。

  • 処理バックエンドとして Auto、D3D、DirectML、CPU を明示的に選択できるようにし、Auto 選択時は利用可能なバックエンドへ自動的にフォールバックするようにしました。


変更 / 改善

  • ネイティブ動画デコード、高速推論経路、回転動画の処理、および最初に顔を検出できなかった場合の復旧により、動画トラッキングの性能と信頼性を向上しました。

  • 独立したアップロード処理と解析処理を並行して実行することで、トレーニングおよび動画処理の待ち時間を短縮しました。

  • セッションおよびプロファイルの読み込み、大規模な Gallery と Video Library の絞り込み、動画のスクラブ、DCC へのアニメーション転送の応答性を向上しました。

  • 読み込み状態、Processor の動画ごとおよび全体の進捗、推定残り時間、キャンセル操作、ステータスバーの警告・エラー表示を改善し、時間のかかる処理の状況を把握しやすくしました。

  • バージョン警告、移行前バックアップ、および互換性のないキャッシュの削除により、異なるバージョン間でのセッション読み込みをより安全にしました。


修正

  • アクセスできない最近使用したセッションの項目を適切に処理し、起動時に最近使用したセッションのメニューが正しく表示されるようにしました。

  • 負の表示タイムスタンプを持つ動画のシークおよびスクラブの問題を修正し、対応動画の末尾で遅延デコードされた最終フレームが失われないようにしました。

  • 動画処理中に UI が操作不能になる問題、およびバックグラウンドジョブが重複して開始される問題を修正しました。

  • Gallery の絞り込み、Editor のタグ候補、および編集後にプロファイルのコントロールが更新されない問題を修正しました。

  • DCC との接続が切れた後の起動および同期状態（Controller Info への読み込みを含む）を修正し、アニメーション転送の性能と Maya 2023 との互換性を向上しました。

  • Controller Info の行の並べ替え、およびネイティブ動画のリサイズ失敗を修正しました。

  • Settings からの再起動、翻訳が空の場合のフォールバック、および公開版ランチャーで不要なコンソールウィンドウが表示される問題を修正しました。
