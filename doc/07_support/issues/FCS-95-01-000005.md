# FCS-95-01-000005

ERROR

## 原因

セッションをコピーする前に、保存先、Actor、Character、対象動画、変更先DCCのシーンを検証します。

## 対処方法

以下の該当する項目を確認し、エクスポート設定を修正してからExportを再実行してください。現在のセッションがコピー元です。

## 考えられる原因

```{raw} html
<span id="required-fields"></span>
```

**エクスポート情報の不足**


エクスポート先を選び、ActorとCharacterの両方を入力してください。保存先は エクスポート先/FCS/Actor/Character になります。

```{raw} html
<span id="source-overlap"></span>
```

**現在のセッションと保存先が重複**


保存先のキャラクターフォルダーは現在のキャラクターフォルダーの外側にしてください。同じ場所、その親フォルダー、その内部は使用できません。エクスポート先、Actor、Characterのいずれかを変更してください。

```{raw} html
<span id="existing-target"></span>
```

**保存先に同じキャラクターが存在**


保存先に同じキャラクターフォルダーがあります。別の保存先またはキャラクター名を選んでください。置き換える場合は、既存のキャラクターをバックアップし、置き換える対象を確認してください。

```{raw} html
<span id="project-video-target"></span>
```

**動画の保存先が現在のプロジェクトと重複**


Associated videos または All files を選択した場合、現在のプロジェクトとは別のフォルダーに出力してください。元動画のコピーが不要な場合は No video を選べます。

```{raw} html
<span id="missing-video"></span>
```

**元動画が見つからない**


Associated videos と All files では、登録された場所に元動画が必要です。元ファイルを復元するか、動画ライブラリでパスを更新してから再実行してください。動画のコピーが不要な場合に限り No video を選択してください。

```{raw} html
<span id="filename-collision"></span>
```

**異なる動画のファイル名が重複**


All files では、同じファイル名の異なる動画を1つの保存先にコピーできません。元ファイルを別々の名前にして動画ライブラリのパスを更新するか、Associated videos を選択してください。

```{raw} html
<span id="maya-scene"></span>
```

**Mayaシーンを開けない**


エクスポート先のDCCをMayaに変更する場合、既存の .ma または .mb シーンを選択してください。拡張子は小文字にしてください。相対パスはエクスポート先を基準に解決されます。シーンを復元するか、実際の場所を選択してください。

```{raw} html
<span id="maya-workspace"></span>
```

**Mayaプロジェクトフォルダーを使用できない**


Mayaに変更する場合、既存のMayaワークスペースフォルダーを選択してください。シーンファイルではなくフォルダーを指定してください。ドライブが使用できない場合は再接続してから選び直してください。

```{raw} html
<span id="blender-scene"></span>
```

**Blenderシーンを開けない**


エクスポート先のDCCをBlenderに変更する場合、既存の .blend シーンを選択してください。拡張子の大文字・小文字は区別しません。相対パスはエクスポート先を基準に解決されます。

```{raw} html
<span id="renderer"></span>
```

**保存されたアプリの選択を使用できない**


エクスポートするセッションのDCCはMayaまたはBlenderを選択してください。他のDCCは使用できません。

```{raw} html
<span id="required-export-session"></span>
```

**エクスポート設定**

選択が不完全な状態で開始されたか、選択済みの内容をFCSが操作に渡せませんでした。

Export Sessionで保存先を選び、ActorとCharacterを入力してから再実行してください。入力済みだった場合は出力画面を開き直し、再発する場合は報告してください。

```{raw} html
<span id="required-export-session-validate"></span>
```

**エクスポート設定**

選択が不完全な状態で開始されたか、選択済みの内容をFCSが操作に渡せませんでした。

Export Sessionで保存先を選び、ActorとCharacterを入力してください。入力済みでも拒否される場合は画面を開き直し、スクリーンショットを添えて報告してください。

```{raw} html
<span id="maya-version"></span>
```

**Mayaのバージョンが非対応**


Maya用の出力では、対応する4桁の年 2018, 2020, 2022, 2023, 2024, 2025, 2026, 2027 から選択してください。

```{raw} html
<span id="blender-version"></span>
```

**Blenderのバージョンが非対応**


Blender用の出力では、対応するメジャー.マイナーバージョン 4.0, 4.1, 4.2, 4.3, 4.4, 4.5 から選択してください。例えば4.5.0ではなく4.5を指定してください。
