# FCS-80-07-000004

ERROR

## メッセージ

動画フレームを反映できませんでした。元動画、出力先フォルダーの書き込み権限、MayaまたはBlenderとの接続を確認してから、Framesを再試行してください。

## 原因

- 指定された動画フレームの準備または配置を完了できませんでした。

## 対処方法

1. 動画フレームを反映できませんでした。元動画、出力先フォルダーの書き込み権限、MayaまたはBlenderとの接続を確認してから、Framesを再試行してください。
