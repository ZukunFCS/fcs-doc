# FCS-40-04-000001

ERROR

## 原因

選択した動画をセッションに追加できませんでした。ファイルの欠落、非対応の形式、動画の読み取り不能などでインポートできない場合があります。

## 対処方法

以下の該当する条件を修正してから再実行してください。再生可能な動画でも失敗する場合は、元の動画を保持してください。

## 考えられる原因

```{raw} html
<span id="video-import-not-found"></span>
```

**動画ファイルが見つからない**

インポート元の動画のパスが存在しません。

動画が見つかりません。インポートする既存の動画ファイルを選択してください。

```{raw} html
<span id="video-import-unsupported-format"></span>
```

**動画の形式が非対応**

元ファイルの拡張子が、FCSで対応する動画コンテナーの拡張子ではありません。

拡張子が .avi, .m2ts, .m4v, .mkv, .mov, .mp4, .mts, .ts のいずれかの既存の動画を選択してください。大文字・小文字は区別しません。これは対応コンテナーの一覧であり、内部のすべてのコーデックに対応する保証ではありません。元動画が再生できてもFCSで読めない場合、拡張子だけ変えず、コピーを再エンコードしてください。

```{raw} html
<span id="video-import-non-ascii-path"></span>
```

**動画のパスにASCII以外の文字がある**

動画のフルパスにASCII以外の文字が含まれています。親フォルダー名とファイル名の両方が検証されます。

動画を、全体がASCII文字のパスに移動またはコピーしてください（例：C:/FCSProject/Facial/RecData/take01.mp4）。名前には英数字、ハイフン、アンダースコアを使用し、空白を含めないでください。親フォルダーが非ASCIIの場合、ファイル名だけ変更しても解決しません。移動先からインポートしてください。

```{raw} html
<span id="video-import-whitespace-path"></span>
```

**動画のパスに空白がある**

動画のフルパスのどこかに、スペースやタブなどの空白文字が含まれています。

動画のファイル名とすべての親フォルダーから空白を除去してください。例えばC:/FCS Project/RecData/take 01.mp4ではなく、C:/FCSProject/RecData/take_01.mp4を使用してください。名前を変更またはコピーした動画を再度インポートしてください。

```{raw} html
<span id="video-metadata-invalid"></span>
```

**動画を読み取れない**

選択した動画から有効なフレーム数とメタデータを読み取れませんでした。

動画のコピーや録画が完了し、プレーヤーで最後まで再生できることを確認してください。完全な元ファイルを選択してください。元動画が再生できてもFCSで読めない場合はコピーを再エンコードし、元ファイルをサポート用に保持してください。

```{raw} html
<span id="video-has-no-frames"></span>
```

**動画フレームを読み取れない**

選択されたファイルから動画フレームを読み取れませんでした。

コピーや録画の完了と、動画全体をプレーヤーで再生できることを確認してください。完全な元動画を選択するか、コピーを再エンコードしてください。再生できる動画でも読み取れない場合は、元ファイルをサポート用に保持してください。

```{raw} html
<span id="unexpected"></span>
```

**FCSで予期しない障害が発生**

動画のインポートで、このページに列挙した入力検証以外の障害が発生しました。技術的な原因の特定には、この操作のログが必要です。

現在のセッションと動画のインポートで作成済みのファイルを保持してください。同じ操作のログのエラーを確認してください。保存できる作業を保存し、一度再実行してください。再発する場合は、このコード、FCSバージョン、操作の設定、ログを添えてBug Feedbackで報告してください。

```{raw} html
<span id="required-video-import"></span>
```

**動画の選択**

選択が不完全な状態で開始されたか、選択済みの内容をFCSが操作に渡せませんでした。

インポート画面で既存の動画を1本以上選択して確定してください。ファイルを選択しても再発する場合は、画面を開き直してから問題を報告してください。

```{raw} html
<span id="required-video-import-preview"></span>
```

**動画のプレビュー**

選択が不完全な状態で開始されたか、選択済みの内容をFCSが操作に渡せませんでした。

インポート画面で元動画を選び直してください。選択済みで再生可能な動画でもプレビューが開かない場合は、動画の形式とFCSバージョンを添えて報告してください。
