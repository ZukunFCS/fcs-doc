# FCS-55-04-000003

ERROR

## 原因

名前変更のプレビューを適用できませんでした。新しい名前の空欄や重複、古い選択内容などで名前を変更できない場合があります。

## 対処方法

以下の該当する条件とプレビューを比較してください。表示された名前がすべて正しいのに失敗する場合は、FCSの問題としてプレビューを報告してください。

## 考えられる原因

```{raw} html
<span id="controller-rename-collision"></span>
```

**新しい名前が使用済み**

変更後の名前同士、または変更対象外のコントローラー名と重複しています。

名前変更のプレビューで、変更後の各名前が一意になるよう修正してください。変更しないコントローラーの名前とも重複しないことを確認してから、再度適用してください。

```{raw} html
<span id="controller-rename-duplicate-source"></span>
```

**名前変更の対象が重複**

同じコントローラーが、名前変更の処理に複数回渡されました。

Rename Controllersを開き直し、対象を選び直してください。プレビューに各コントローラーが1回ずつ表示されているのに再発する場合は、そのスクリーンショットを添えて報告してください。

```{raw} html
<span id="controller-rename-length-mismatch"></span>
```

**名前変更のプレビューが不完全**

選択した各コントローラーの新しい名前をFCSが正しく保持できず、変更前に処理を停止しました。

Rename Controllersを開き直し、対象を選び直してプレビューを作成してください。完全なプレビューでも失敗する場合は、FCSの名前変更の問題として報告してください。

```{raw} html
<span id="controller-rename-empty"></span>
```

**新しい名前が空欄**

名前変更のプレビューで、少なくとも1つの新しい名前が空欄になっています。

Rename Controllersでプレビューを確認し、選択したすべてのコントローラーの名前を入力してから適用してください。名前が表示されているのに拒否される場合は、プレビューのスクリーンショットを添えて報告してください。

```{raw} html
<span id="unknown-controller"></span>
```

**選択したコントローラーが存在しない**

画面を開いた後に、コントローラーが名前変更または削除された可能性があります。

コントローラ画面を開き直し、現在のコントローラーを選び直してください。一覧に表示されているのに使用できない場合は、名前と失敗した操作を報告してください。

```{raw} html
<span id="unexpected"></span>
```

**FCSで予期しない障害が発生**

コントローラー名の変更で、このページに列挙した入力検証以外の障害が発生しました。技術的な原因の特定には、この操作のログが必要です。

現在のセッションとコントローラー名の変更で作成済みのファイルを保持してください。同じ操作のログのエラーを確認してください。保存できる作業を保存し、一度再実行してください。再発する場合は、このコード、FCSバージョン、操作の設定、ログを添えてBug Feedbackで報告してください。

```{raw} html
<span id="required-controller-rename-many"></span>
```

**名前変更のプレビュー**

選択が不完全な状態で開始されたか、選択済みの内容をFCSが操作に渡せませんでした。

Rename Controllersを開き直し、対象を選び直してプレビューを確認してから適用してください。完全なプレビューでも拒否される場合は報告してください。名前の変更は完了していません。
