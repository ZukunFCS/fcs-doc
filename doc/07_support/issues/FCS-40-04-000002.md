# FCS-40-04-000002

ERROR

## 原因

選択した動画をグループにできませんでした。選択内容やグループ名が既存のグループと重複している場合があります。

## 対処方法

以下の説明で選択した動画とグループ名を確認してから、再度グループを作成してください。

## 考えられる原因

```{raw} html
<span id="video-folder-name-duplicate"></span>
```

**グループ名が使用済み**

動画ライブラリに同じ名前の動画グループが存在します。

別のグループ名を指定するか、既存のグループを使用してください。これは動画ライブラリ内のグループ名の問題です。無関係なディスク上のフォルダーを変更しても解決しません。

```{raw} html
<span id="video-folder-same-video"></span>
```

**同じ動画を2回選択している**

動画グループの作成に指定した2つの入力が同じ動画です。

動画ライブラリで異なる2つの動画を選択してから、再度グループを作成してください。同じ項目を2回選択しても、2本の動画にはなりません。

```{raw} html
<span id="video-folder-create-requires-ungrouped"></span>
```

**動画が別のグループに所属している**

新しいグループに指定した動画の少なくとも1つが、既存の動画ライブラリグループに属しています。

現在どのグループにも属していない2本の動画を選択するか、先に対象の動画を既存のグループから外してください。その後で新しいグループを作成してください。

```{raw} html
<span id="video-not-registered"></span>
```

**動画がこのセッションに登録されていない**

選択した動画が現在のセッションの動画ライブラリに登録されていません。

現在のセッションの動画ライブラリに動画をインポートし、登録された項目を選択してください。別のセッションで開いただけでは、現在のセッションには登録されません。

```{raw} html
<span id="unexpected"></span>
```

**FCSで予期しない障害が発生**

動画グループの作成で、このページに列挙した入力検証以外の障害が発生しました。技術的な原因の特定には、この操作のログが必要です。

現在のセッションと動画グループの作成で作成済みのファイルを保持してください。同じ操作のログのエラーを確認してください。保存できる作業を保存し、一度再実行してください。再発する場合は、このコード、FCSバージョン、操作の設定、ログを添えてBug Feedbackで報告してください。

```{raw} html
<span id="required-video-folder-create"></span>
```

**動画グループの選択**

選択が不完全な状態で開始されたか、選択済みの内容をFCSが操作に渡せませんでした。

グループに属していない異なる2本の動画を選び、グループ名を入力してから作成してください。設定済みでも拒否される場合は動画ライブラリを開き直し、問題を報告してください。
