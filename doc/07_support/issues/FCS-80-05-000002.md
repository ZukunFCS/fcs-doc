# FCS-80-05-000002

ERROR

## 原因

セッションまたはアプリの選択が、このFCSビルドで使用できないBlenderバージョンを参照しています。

## 対処方法

実際にインストールされているBlenderバージョンを確認し、セッションまたはアプリの設定で選択してください。このFCSビルドの対応バージョンは 4.0, 4.1, 4.2, 4.3, 4.4, 4.5 です。非対応のバージョンを使用している場合は、対応するFCSビルドを使用するか、管理者に対応バージョンの導入を相談してください。FCSに表示されたバージョンでも失敗する場合は、そのバージョンとFCSバージョンを報告してください。
