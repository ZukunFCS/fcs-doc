# FCS-50-02-000006

ERROR

## メッセージ

プロファイルの信頼度を計算できませんでした。信頼度スコアを使用できない可能性があります。サポートにお問い合わせください。

## 原因

- 信頼度の計算で、使用可能なプロファイルの準備、比較用ソルバーの学習、またはスコアの計算に失敗しました。

## 対処方法

1. 選択したプロファイルの元画像を読み取れ、現在のコントローラー値があることを確認してください。現在の設定で学習してから信頼度を再計算してください。代替のスコアは信頼度が不明な状態として扱い、プロファイルが正確である証拠とは判断しないでください。再発する場合は計算時のログを添えてBug Feedbackで報告してください。
