# FCS-90-99-000001

ERROR

## メッセージ

保存に失敗しました。サポートにお問い合わせください。出力済みのファイルを保持し、ヘルプで復旧手順を確認してください。

## 原因

- 保存中に、より具体的な入力検証エラーに分類できない例外が発生しました。

## 対処方法

1. FCSを閉じずに未保存の編集を保持してください。保存先が存在し書き込み可能か確認し、共有ストレージには再接続してください。再試行後も失敗する場合は編集を破棄する前に報告してください。
2. 未保存の作業と出力済みのファイルを保持してください。表示されたコードとログのメッセージをコピーし、操作内容、時刻、FCSバージョン、対象の入力を記録してください。
3. 指定された確認後も同じ操作で失敗する場合は、これらの情報を添えてBug Feedbackから報告してください。ローカルに保存された報告は、サーバーへの送信完了を意味しません。
