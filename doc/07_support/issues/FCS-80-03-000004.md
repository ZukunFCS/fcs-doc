# FCS-80-03-000004

ERROR

## メッセージ

タイムラインの同期が停止しました。MayaまたはBlenderに再接続してから、同期を有効にし直してください。

## 原因

- 現在のDCC接続では、指定したタイムラインの同期を完了できませんでした。

## 対処方法

1. タイムラインの同期が停止しました。MayaまたはBlenderに再接続してから、同期を有効にし直してください。
2. 未保存の作業と出力済みのファイルを保持してください。表示されたコードとログのメッセージをコピーし、操作内容、時刻、FCSバージョン、対象の入力を記録してください。
3. 指定された確認後も同じ操作で失敗する場合は、これらの情報を添えてBug Feedbackから報告してください。ローカルに保存された報告は、サーバーへの送信完了を意味しません。
