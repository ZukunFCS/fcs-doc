# FCS-50-04-000001

ERROR

## 原因

編集したプロファイルの保存に失敗しました。修正して再度保存できるよう、編集画面に下書きを保持しています。

## 対処方法

下書きを保持するため、エディタを開いたままにしてください。プロファイル名、元画像、現在のコントローラーデータと、プロジェクトへの書き込み権限を確認して再度Saveしてください。再発する場合は再起動前に前後のログをコピーしてください。画面を閉じると未保存の編集内容を失う可能性があります。
