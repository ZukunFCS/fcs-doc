## Maya・Blenderへの出力

| コード | 説明 |
| --- | --- |
| [FCS-80-03-000001](FCS-80-03-000001.md) | MayaまたはBlenderに接続できません。アプリケーションを開き、FCSプラグインを有効にしてから、もう一度お試しください。 |
| [FCS-80-03-000002](FCS-80-03-000002.md) | MayaまたはBlenderへの出力を完了できませんでした。対象のアプリケーションとシーンを開き、FCSとの接続を確認してから、要求した出力を再試行してください。 |
| [FCS-80-03-000004](FCS-80-03-000004.md) | タイムラインの同期が停止しました。MayaまたはBlenderに再接続してから、同期を有効にし直してください。 |
| [FCS-80-03-000005](FCS-80-03-000005.md) | タイムラインの同期が停止しました。MayaまたはBlenderに再接続してから、同期を有効にし直してください。 |
| [FCS-80-03-000006](FCS-80-03-000006.md) | MayaまたはBlenderへの出力を開始できませんでした。対象のアプリケーションとシーンを開き、FCSとの接続を確認してから再試行してください。 |

## ストレージとNAS

| コード | 説明 |
| --- | --- |
| [FCS-90-03-000002](FCS-90-03-000002.md) | NASまたはネットワークドライブ上の一時メディアファイルを削除できませんでした。ネットワーク接続を確認し、ドライブに再接続してください。出力済みのファイルは保持されています。 |
| [FCS-90-03-000003](FCS-90-03-000003.md) | メディア出力中にNASまたはネットワークドライブにアクセスできませんでした。ネットワーク接続を確認し、ドライブに再接続してから、もう一度出力してください。 |
