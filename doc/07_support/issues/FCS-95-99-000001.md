# FCS-95-99-000001

ERROR

## メッセージ

エクスポートに失敗しました。サポートにお問い合わせください。出力済みのファイルを保持し、ヘルプで復旧手順を確認してください。

## 原因

- 保存先や元ファイルの既知の検証以外の例外により、エクスポートが停止しました。

## 対処方法

1. 選択した出力、元ファイル、保存先へのアクセス、NAS接続を確認してください。セッションのエクスポート先は現在のセッションの外側を選び、既存の作業を保持して再発を報告してください。
2. 未保存の作業と出力済みのファイルを保持してください。表示されたコードとログのメッセージをコピーし、操作内容、時刻、FCSバージョン、対象の入力を記録してください。
3. 指定された確認後も同じ操作で失敗する場合は、これらの情報を添えてBug Feedbackから報告してください。ローカルに保存された報告は、サーバーへの送信完了を意味しません。
